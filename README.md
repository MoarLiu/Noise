# Noise

白噪音番茄闹钟。

Noise 是一个本地优先的 macOS 专注 App，把番茄计时、白噪音声景、菜单栏倒计时和轻量专注统计放在一起。

## 当前 MVP

- 番茄计时：专注、短休息、长休息、暂停、继续、停止。
- 循环计划：自定义时长、长休息间隔、自动开始下一轮。
- 声景：专注声音、休息声音、音量控制。
- 声景管理：分组声音选择、声景预设、声音试听。
- 通知：番茄/休息完成后发送 macOS 通知。
- 记录：今日专注、近 7 天统计、高频任务、CSV/Markdown 导出。
- 菜单栏：状态、快速开始、暂停继续、打开主窗口。
- 打包：本地 `.app` 和 DMG 生成脚本。

## 界面与操作

- 默认使用极简数字计时界面；「工作台」可展开导航和最近任务，选择会在暂停、继续时保持。
- 顶部可切换专注、声景、记录；计时规则、声音淡入淡出和行为设置统一在设置窗口中管理。
- 任务可留空。点击最近任务只填入内容，点击开始按钮才会计时。
- 非文本编辑状态下，Return 开始当前模式，空格暂停或继续；编辑任务时，Return 只提交文字。
- 计时或暂停时，时长预设和模式选择锁定；在设置中修改时长会在下一轮生效。
- 选声和声景组合保留当前音量；静音独立保存，取消静音会恢复原音量。
- 提前结束不会计入完成记录；完成后显示本轮结果，可选择休息或再专注一轮。
- 默认窗口为 980 × 720，最小内容尺寸为 680 × 640，支持系统深色模式。
